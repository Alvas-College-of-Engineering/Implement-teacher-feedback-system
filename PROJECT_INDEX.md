## 📂 Project Files Explained

### Source Code (Java Files)

#### 1. **Feedback.java** (Data Model)
**Purpose**: Represents a single feedback entry
**Key Features**:
- Encapsulated attributes (teacher, subject, rating, comment)
- Getter methods only (no setters)
- CSV serialization (toString())
- CSV deserialization (fromCSV())

**When to edit**: To add new feedback attributes or change data structure

```java
Example Usage:
Feedback fb = new Feedback("Dr. Smith", "Math", 5, "Excellent teaching!");
System.out.println(fb.getRating());  // 5
```

---

#### 2. **FeedbackManager.java** (Business Logic)
**Purpose**: Manages feedback storage, retrieval, and calculations
**Key Features**:
- ArrayList<Feedback> for in-memory storage
- File I/O with BufferedReader/Writer
- Average rating calculations
- No duplicate loading (flag mechanism)
- Auto-creates file if missing

**When to edit**: To add features like filtering, sorting, or export

```java
Example Usage:
FeedbackManager manager = new FeedbackManager();
manager.loadFeedback();
Map<String, Double> averages = manager.getAverageRatings();
```

---

#### 3. **FeedbackUI.java** (User Interface - Main Class)
**Purpose**: Complete Swing GUI for the application
**Key Features**:
- Clean, professional form interface
- Input validation with error dialogs
- Summary window with tabbed view
- JTable for all feedback entries
- Success/error notifications

**When to edit**: To customize colors, window size, or add new GUI elements

```java
To run:
java FeedbackUI
```

## 📞 Common Tasks

### Task: Add a new field to feedback
1. Edit Feedback.java (add private attribute)
2. Edit constructor
3. Add getter method
4. Update toString() and fromCSV()
5. Recompile: `javac *.java`

### Task: Change window size
1. Edit FeedbackUI.java
2. Find `setSize(500, 600);`
3. Change numbers as needed
4. Recompile and run

### Task: Change color scheme
1. Edit FeedbackUI.java
2. Find `setBackground(new Color(...))`
3. Change RGB values
4. Recompile and run

### Task: Export feedback to PDF
1. Add iText library dependency
2. Create ExportManager class
3. Add "Export PDF" button to UI
4. Implement PDF generation
